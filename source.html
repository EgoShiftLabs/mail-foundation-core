Verify it yourself

Three checks worth an hour.

  • Read the authentication routes and confirm sign-in verifies a message signature — and that no code path constructs or submits a transaction.
  • Search the codebase for any request for a seed phrase or private key. There isn't one, and there never legitimately will be.
  • Run the adversarial harness against your own local instance and watch the 36 scenarios execute.
