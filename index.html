The idea

The address is already there. $MAIL adds the mailbox.

A Solana wallet already has a public address.

$MAIL gives that address another function: a mailbox.

  • No username.
  • No email address.
  • No phone number.

Wallet ownership is proven through a signed authentication message — a message signature, never a transaction.

Basic V1 mail is free.

How a letter travels

From address to opened, honestly.

Wallet addressAny valid Solana wallet.
↓
Mailbox addressThe same address, now receivable.
↓
Letter addressedMail is accepted and waits.
↓
Owner authenticatesA signed message proves control.
↓
DeliveredThe recipient reaches their mail.
↓
OpenedThe recipient opens the letter.
Addressed
The system accepted correspondence addressed to the wallet.
Delivered
The authenticated recipient reached an appropriate $MAIL surface.
Opened
The authenticated recipient explicitly opened the correspondence.

$MAIL never claims “delivered” while mail merely waits, and never claims “opened” without an explicit open. These states are truthful by rule — everywhere, including this website.

What V1 includes

A complete consumer mailbox, kept deliberately small.

Letters

Wallet-to-wallet correspondence between Solana addresses, with replies and threads that stay letters — not chat bubbles.

Requests

First contact from an unknown sender arrives as a request the recipient can accept, decline, or junk.

Recipient safety

Junk, blocking with RETURN TO SENDER refusal, reporting, and link-destination warnings — all in the recipient's hands.

Private by default

Share that you got mail without revealing the letter: share cards never contain the message body.

V1 is a security-tested proof of concept with its technical source published for independent review. Read Security & Trust for the exact claims and their limits.
